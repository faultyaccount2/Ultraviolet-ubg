Welcome to Scramjet

Bromine workspace · Isolated Scramjet frontend

Scramjet is an experimental interception-based browser engine. Enter a website above to open it in an isolated page.

Use the workspace tabs to inspect requests, experiment with a sandboxed page, or tune the connection. Site behavior can vary, and first-party security checks may still require opening a site directly.

Network transport

Bare sends proxied HTTP through its configured endpoint. Wisp uses the Wisp server you enter to create TCP connections.

Choose Wisp only when you have an endpoint and permission to use it. A successful WebSocket connection does not by itself confirm the Wisp protocol or destination access.
